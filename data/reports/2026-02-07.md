## AI最新ニュース

### TechCrunch Anthropic

- **WordPressとClaudeの新しい連携が容易に**

  WordPressは新しいClaudeコネクターを公開し、サイト所有者がバックエンドデータをAnthropicのAIチャットボットと共有できるようになりました。ユーザーは共有したい特定データを管理でき、必要に応じてアクセスを取り消せます。重要な点として、Claudeには読み取り専用アクセスのみが付与され、CMS内のデータ変更はできません。将来的には書き込みアクセスも提供予定で、ユーザーは接続されたAIを通じて編集作業を直接実行できるようになる見込みです。

  🔗 https://techcrunch.com/2026/02/06/it-just-got-easier-for-claude-to-check-in-on-your-wordpress-site/

## Claude Code

### Claude Code GitHub Releases

- **v2.1.34**

  バグ修正に焦点を当てたマイナーアップデートです。主な変更点として、レンダリング中にエージェントチーム設定が変更された場合のクラッシュを修正しました。また、サンドボックスから除外されたコマンドが`autoAllowBashIfSandboxed`が有効な場合でもBashの権限チェックをバイパスできる脆弱性を修正し、セキュリティを強化しました。

  🔗 https://github.com/anthropics/claude-code/releases/tag/v2.1.34

- **v2.1.33**

  マルチエージェントワークフロー機能の強化と、ユーザー体験の改善に焦点を当てたリリースです。agent teammateセッションの修正と新しい`TeammateIdle`および`TaskCompleted`フックイベントの追加により、複数エージェント間の通信が改善されました。また、メモリ機能の導入（`user`、`project`、`local`スコープ対応）とタスク実行時のサブエージェント制限機能により、エージェント制御がより柔軟になります。さらに、VSCodeでのリモートセッション対応、エラーメッセージの詳細化、APIプロキシ互換性の修正など、開発体験全般が向上しています。

  🔗 https://github.com/anthropics/claude-code/releases/tag/v2.1.33

## AI音楽・音声生成

### SUNO AI 公式

- **What's New in Suno Studio 1.2**

  Suno Studio 1.2では、クリエイターがより高度な制御を実現できる4つの新機能が追加されました。「Remove FX」機能では、オーディオクリップから効果を除去して、ユーザーが独自のプラグイン設定を適用できます。「Warp Markers with Quantize」により、オーディオのタイミングと溝を調整し、録音をグリッドに合わせることが可能です。また、「Alternates」機能で複数のサウンドバリエーションを1つのトラックで管理でき、「Time Signature Support」により4/4以外の拍子記号（6/8や7/8など）に対応しました。

  🔗 https://suno.com/blog/studio1_2
