- **Apple XcodeがClaude Agent SDKに対応**

  AppleのXcode 26.3は、Claude Agent SDKのネイティブ統合を導入しました。これにより、開発者はXcode内でClaudeが長時間実行される自律的なコーディングタスクに対応できるようになります。主な機能として、Xcode Previewsをキャプチャして視覚的に検証する能力、プロジェクト全体の構造を理解する推論機能、そしてユーザーの入力なしに目標を達成するまで自動的に実行する能力が含まれています。この統合により、開発者は個別の指示ではなく目標を指定でき、Claudeが自動的にタスクを分解して実行します。これはAppleプラットフォーム開発を大幅に効率化する重要な進展です。

  🔗 https://anthropic.com/news/apple-xcode-claude-agent-sdk

- **Anthropic、Allen InstituteとHHMIとの科学研究加速パートナーシップを発表**

  Anthropicは、Allen InstituteとHoward Hughes Medical Institute(HHMI)との2つの重要なパートナーシップを発表しました。これらの協力により、Claudeの機能を最先端の科学研究に拡張し、科学者チームがより効果的に協働できる環境を構築します。HHMIとの協力ではJanelia Research Campusを中心に、AIエージェントの開発を進め、実験プロセスを変革します。一方、Allen Instituteとの協力では、多様なデータ分析を支援する複数のAIエージェントシステムを構築予定です。両パートナーシップは透明性と科学的厳密性を重視し、AIを人間の判断を補強するツールとして位置づけています。これは生命科学研究におけるAI活用の新たな標準を確立する可能性を示唆しています。

  🔗 https://anthropic.com/news/anthropic-partners-with-allen-institute-and-howard-hughes-medical-institute

- **Claude Code v2.1.30 リリース**

  Claude Code v2.1.30では、PDFの特定ページ範囲を読み込めるpagesパラメータが追加され、大型PDFは軽量な参照形式で返されるようになりました。MCPサーバー向けにOAuthクライアント認証情報の事前設定が追加され、/debugコマンドでセッションのトラブルシューティングが可能になりました。メモリ使用量が68%削減され、セッション再開時のパフォーマンスが大幅に向上しています。また、プロンプトキャッシュの無効化ロジックの修正や、複数のバグ修正（WindowsでのBashコマンド実行、サブエージェントのMCPツール同期など）が含まれています。VSCode統合では、質問ダイアログでの複数行入力サポートが追加されました。

  🔗 https://github.com/anthropics/claude-code/releases/tag/v2.1.30
