## 技術ブログ

### GitHub Blog

- **Continuous AI実践：エージェント型CIで開発者が今日自動化できること**
  Continuous AIは、リポジトリで推論が必要なタスクを処理するバックグラウンドエージェントのパターンです。従来のCI/CDは「テスト成功/失敗」など決定論的なルールに基づいていますが、ドキュメントと実装の不一致検出など意図の理解が必要な作業には対応できません。開発者は自然言語でワークフローを定義でき、エージェントは「pull requestを作成する」などの明確な出力権限のみを持つ設計になっています。実践的には、ドキュメント修正の自動提案、依存関係の変更検出、テスト自動生成など、今日でも多くのタスクを自動化できます。

  🔗 https://github.blog/ai-and-ml/generative-ai/continuous-ai-in-practice-what-developers-can-automate-today-with-agentic-ci/

### Claude Code GitHub Releases

- **Claude Code v2.1.32リリース**
  このリリースの主な変更点として、Claude Opus 4.6が利用可能になり、マルチエージェント協調作業のための研究プレビュー版エージェントチーム機能が追加されました。Claudeは会話中の記憶を自動的に記録・回想できるようになり、部分的な会話要約が可能な「ここから要約」機能が実装されました。バグ修正としては、@ファイル補完の相対パス表示、Bashツールのヘレドック処理、VSCodeのスラッシュコマンド実行の問題が解決され、タイ語・ラオス語の文字列表示も改善されました。スキル文字予算がコンテキストウィンドウに応じて拡大（コンテキストの2%）し、より多くのスキル説明を表示できるようになりました。

  🔗 https://github.com/anthropics/claude-code/releases/tag/v2.1.32
