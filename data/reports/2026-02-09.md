## Claude Code

### Claude Code GitHub Releases

- **v2.1.37**

  このリリースは、`/extra-usage`を有効にした後、`/fast`コマンドが即座に利用可能にならないという問題を修正しました。この修正により、ユーザーが追加使用量オプションを有効化した際に、高速実行モードへのアクセスが正常に機能するようになります。このバグ修正は、開発者のワークフローをスムーズにし、予期しない遅延なく機能を利用できるようにするため重要です。

  🔗 https://github.com/anthropics/claude-code/releases/tag/v2.1.37

- **v2.1.36**

  このリリースでは、Opus 4.6モデルに対してFast mode（高速モード）が利用可能になったことが主な追加機能です。Fast modeにより、ユーザーはより迅速にコード生成や分析を行うことができるようになり、開発効率が向上します。このアップデートは、Opus 4.6ユーザーの生産性向上と、より応答性の高い開発体験の提供を実現する重要な改善となっています。

  🔗 https://github.com/anthropics/claude-code/releases/tag/v2.1.36

## AI音楽・音声生成

### SUNO AI 公式

- **What's New in Suno Studio 1.2**

  Sunoが音楽制作プラットフォーム「Suno Studio」のバージョン1.2をリリースしました。このアップデートでは、「Remove FX」機能によりオーディオから効果音を除去でき、「Warp Markers」でタイミング調整が可能になります。さらに「Alternates」機能で複数のバリエーションを管理しやすくなり、「Time Signature Support」により4/4以外の拍子記号にも対応するようになりました。

  🔗 https://suno.com/blog/studio1_2

### TechCrunch AI音楽

- **Deezer makes it easier for rival platforms to take a stance against AI-generated music**

  音楽ストリーミングサービスのDeezerが、AI生成音楽を検出するツールを他のプラットフォームに提供することを発表しました。昨年導入されたこのツールは、完全にAIで生成された楽曲に自動的にタグを付け、アルゴリズムと編集による推奨から除外します。Deezerは、このテクノロジーを業界全体で利用可能にすることで、AI生成曲の増加と詐欺的ストリームに対処する支援を目指しています。

  🔗 https://techcrunch.com/2026/01/29/deezer-makes-it-easier-for-rival-platforms-to-take-a-stance-against-ai-generated-music/
