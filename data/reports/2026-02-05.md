- **Claude is a space to think**
  Anthropicは、Claude内での広告掲載を永遠に行わないという明確な立場を発表しました。同社は「広告による収益化は、AIアシスタントが本来果たすべき真摯な支援という原則と相容れない」と述べており、広告インセンティブが導入されると企業の利益と利用者の利益が衝突する可能性があると懸念しています。Anthropicは「エンタープライズ契約と有料購読を通じた収益化」に専注し、その収益を製品改善に再投資する方針で、教育機関や非営利団体への無料提供も拡大しています。この立場は、ノートブックや良く設計されたツールに広告がないのと同様に、「Claudeも同じように機能すべき」というビジョンに基づいています。

  🔗 https://anthropic.com/news/claude-is-a-space-to-think

## Claude Code

### Claude Code GitHub Releases

- **Claude Code v2.1.31リリース**
  このリリースでは、セッション終了時に会話を後で続ける方法を示すヒントが追加され、日本語IMEの全角スペース入力に対応しました。システムプロンプトが改善され、bash相当コマンド（cat、sed、grep、find）の代わりに専用ツール（Read、Edit、Glob、Grep）の使用が促進されます。バグ修正として、PDFが大きすぎるエラーでセッションがロックアップする問題の永続的な修正、サンドボックスモード有効時のbashコマンドの"Read-only file system"エラーの修正、プロジェクト設定に必須フィールドがない場合のクラッシュの修正などが含まれます。UI/UX向上として、PDFとリクエストサイズのエラーメッセージに実際の制限値（100ページ、20MB）を表示し、ターミナルのレイアウトジッターを削減しました。

  🔗 https://github.com/anthropics/claude-code/releases/tag/v2.1.31
