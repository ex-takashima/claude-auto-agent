## Claude Code

### Claude Code GitHub Releases

- **v2.1.39**
  このリリースでは、主にパフォーマンス改善とバグ修正が実施されました。ターミナルレンダリングのパフォーマンスが向上し、致命的エラーが正しく表示されるようになりました。また、セッション終了後のプロセスハング、ターミナル画面境界での文字損失、および詳細トランスクリプトビューの空行表示の問題が修正されています。

  このリリースでは、複数のバグ修正とセキュリティ改善が行われました。VS Codeのターミナルスクロール機能の回帰、Tabキーがスラッシュコマンドをキューイングしてしまう問題、ストリーミング非使用時のテキスト消失、セッション重複などが修正されています。また、heredocデリミタの解析改善によるコマンドスマグリング防止、サンドボックスモードでの`.claude/skills`ディレクトリへの書き込み遮断といったセキュリティ強化も含まれています。
