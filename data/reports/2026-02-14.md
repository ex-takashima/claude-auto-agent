## AI最新ニュース

### Anthropic公式

- **Anthropic partners with CodePath to bring Claude to the US's largest collegiate computer science program**

  Anthropic は米国最大の大学コンピュータサイエンス教育プロバイダーである CodePath と提携し、20,000 以上の学生に Claude AI ツールへのアクセスを提供します。低所得家庭の学生（40%以上）を含む、従来は恵まれていない大学の学生たちが最先端の AI 開発スキルを習得できるようになります。この取り組みは、AI 教育機会の不平等を縮小し、技術業界でのキャリア準備を加速することを目指しています。

  🔗 https://anthropic.com/news/anthropic-codepath-partnership

- **Chris Liddell appointed to Anthropic's board of directors**

  クリス・リデル氏がAnthropicの取締役会に任命されました。彼は30年以上の経営経験を持ち、マイクロソフト、ゼネラルモーターズ、インターナショナルペーパーのCFOを務めた他、トランプ前政権下でホワイトハウスの副主任補佐官を歴任しています。「AIが社会に与える影響が高まる中、彼のような判断力と経験がまさに必要」とコメントされており、この人事は企業のコンプライアンス強化とAI倫理への取り組みを示す動きとして意義があります。

  🔗 https://anthropic.com/news/chris-liddell-appointed-anthropic-board

### TechCrunch Anthropic

- **Anthropic's Super Bowl ads mocking AI with ads helped push Claude's app into the top 10**

  アンスロピックのスーパーボウル広告キャンペーンが、同社のAIアシスタント「Claude」のアプリダウンロードを大幅に増加させました。この広告は「AIを使った広告をからかう」というユニークなアプローチで話題となり、新しいOpus 4.6モデルのリリースと相まって、ClaudeアプリをAppStoreの上位10位にランクインさせるのに成功しました。この成功は、ChatGPTとの差別化を明確に示す効果的なマーケティング戦略が、消費者の関心を引き付けられることを示しています。

  AI企業のAnthropicが、シリーズGラウンドで30億ドルの資金調達を実施し、企業価値を380億ドルに引き上げました。この資金調達により、同社はOpenAIとの競争をさらに激化させ、顧客獲得と市場での認知度向上に向けた取り組みを強化する見通しです。このニュースは、AI業界における急速な資本流入と企業価値の上昇トレンドを示しており、Anthropicの成長戦略を支えるものとなっています。

  🔗 https://techcrunch.com/2026/02/12/anthropic-raises-another-30-billion-in-series-g-with-a-new-value-of-380-billion/

### GitHub Blog

- **Automate repository tasks with GitHub Agentic Workflows**

  GitHub は「GitHub Agentic Workflows」という技術プレビュー機能を発表しました。これは GitHub Actions 内で AI コーディングエージェントを使用して、リポジトリの自動化タスクを実行するものです。開発者は Markdown で目的を記述するだけで、問題のトリアージ、ドキュメント更新、コード品質改善などを自動化できます。セキュリティに重点が置かれており、デフォルトでは読み取り専用権限で実行され、「安全な出力」を通じた明示的な承認が必要です。

  🔗 https://github.blog/ai-and-ml/automate-repository-tasks-with-github-agentic-workflows/

- **Welcome to the Eternal September of open source. Here's what we plan to do for maintainers.**

  オープンソースへの貢献パターンが変化しており、メンテナーが増加する提出物を管理するための新しいアプローチを採用していることについて解説しています。

  🔗 https://github.blog/open-source/maintainers/welcome-to-the-eternal-september-of-open-source-heres-what-we-plan-to-do-for-maintainers/

## Claude Code

### Claude Code GitHub Releases

- **v2.1.42**

  Claude Codeのv2.1.42がリリースされました。このバージョンでは3つの主な改善が行われています。`/resume`コマンドでセッションタイトルとして割り込みメッセージが表示される問題を修正、Bedrock、Vertex、Foundryユーザー向けにOpus 4.6ローンチアナウンスが不適切に表示される問題を修正、複数画像の寸法制限エラーに対して`/compact`提案を含むより分かりやすいエラーメッセージを提供するようになりました。

  🔗 https://github.com/anthropics/claude-code/releases/tag/v2.1.42

- **v2.1.41**

  Claude Code v2.1.41では、複数の重要な修正と新機能が追加されました。`claude auth login`、`claude auth status`、`claude auth logout`のCLIサブコマンドが追加され、Windows ARM64ネイティブバイナリのサポートが追加されました。また、AWS認証の更新が無制限にハングする問題を3分のタイムアウト追加で解決し、ファイル参照のアンカーフラグメント（例：`@README.md#installation`）での解決失敗を修正しました。

  🔗 https://github.com/anthropics/claude-code/releases/tag/v2.1.41
